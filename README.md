# Diplom_3 - Тестирование UI сервиса Stellar Burger

Автоматизированные тесты для UI сайта [Stellar Burger](https://stellarburgers.education-services.ru/).
Проект проверяет следующие функциональности:
- Основная функциональность
- Раздел "Лента заказов"

## Реализованные тесты (16 тестов):

### 1-10. Тесты основной функциональности (Браузеры: Chrome, Firefox)
- `test_transition_to_orders_list_page` — проверка перехода на раздел "Лента заказов" нажатием на кнопку перехода в заголовке главной страницы сервиса
- `test_transition_to_main_page` — проверка перехода на раздел "Конструктор" нажатием на кнопку перехода в заголовке страницы сервиса  "Лента заказов"
- `test_ingredient_details_window_appearance` — проверка появления всплывающего окна с деталями при нажатии на ингредиент на главной странице сервиса
- `test_ingredient_details_window_closing` — проверка закрытия всплывающего окна с деталями ингредиента при нажатии на кнопку закрытия
- `test_increasing_the_counter_of_ingredients` — проверка увеличения счетчика ингредиента при его добавлении в конструктор

### 11-16. Раздел "Лента заказов" (Браузеры: Chrome, Firefox)
- `test_increasing_counter_for_all_time` — проверка увеличения счетчика "Выполнено за всё время" при создании заказа
- `test_increasing_counter_for_today` — проверка увеличения счетчика "Выполнено за сегодня" при создании заказа
- `test_number_appearance_in_orders_list_section` — проверка появления номера заказа в разделе "В работе" в разделе "Лента заказов" после оформления заказа

## Установить зависимости
pip install -r requirements.txt

## Запуск тестов
pytest -v tests/

allure open allure_report
